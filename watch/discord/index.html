Put your watch on Discord.

Show the movie or episode you’re watching, its poster, and playback progress when available.

Use the PreMiD browser extension with Discord desktop. You don’t need to run a server.

  1. Install PreMiD and open Discord desktop. Enable activity sharing in Discord.
  2. Download the compiled OPwatch activity ZIP. Keep it zipped.
  3. In PreMiD settings, enable Activity Developer Mode. In its Developer tab, choose Load Compiled Activity (or the activity ZIP upload button) and select opwatch-premid.zip.
  4. Open a movie or episode on OPwatch and turn Discord sharing on below the player.

This activity is available as a manual installation and is not yet published in the PreMiD store. Installing PreMiD alone does not install OPwatch.

Sharing starts off. Turn it off or close the player to clear the activity on PreMiD’s next update. Some embedded players provide title and episode information only; pause status and timers depend on playback access.
