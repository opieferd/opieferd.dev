# Legacy Watch Discord RPC helper

The current website uses the PreMiD browser extension and no longer sends
requests to this Node helper. Visitors do not need to run it or host a server.

Use the [OPwatch PreMiD activity](../premid/OPwatch/README.md) instead. The
site includes a setup page at `/watch/discord/` and a downloadable compiled
package for manual installation in PreMiD. The active integration uses Discord
application ID `1558711400132640918`.

The old server is retained here for reference and is not part of the current
setup or deployment.
